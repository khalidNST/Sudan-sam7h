# تحدّي السودان 🇸🇩

**العب الحين:** https://khalidnst.github.io/Sudan-sam7h/

لعبة أسئلة ويب سودانية للاعب واحد، بتصميم «بيت نوبي». تشتغل على الجوال والتابلت واللابتوب والتلفزيون، وبعد أول تحميل تشتغل بدون إنترنت.

**الأقسام:**

| القسم | المحتوى | العدد |
|---|---|---|
| الفنانين | عمالقة الطرب والمطربون الجدد | 14 |
| الرابرز | جيل الراب السوداني | 9 |
| البيت السوداني | أغراض البيت (15)، كلمات اللهجة (35)، الترندات (2) | 52 |
| الأدب السوداني | روايات وشعر وأدباء (مسودة تحتاج مراجعة) | 10 |

## التشغيل على جهازك

### الطريقة السهلة (ويندوز)

اضغط مرتين على **`Start-Game.bat`** داخل مجلد اللعبة. تفتح نافذة سوداء، وبعدها بثانيتين تفتح اللعبة في المتصفح على `http://localhost:8765`. خلّ النافذة السوداء مفتوحة وانت تلعب، ولما تخلص اقفلها.

### الطريقة اليدوية

اللعبة HTML و CSS و JavaScript عادي، بدون أي مكتبات أو خطوة بناء. بس لازم تفتحها من سيرفر محلي (مو بالضغط مرتين على الملف)، لأنها تقرأ الأسئلة من `data/questions.json`.

من داخل مجلد `sudan-challenge`:

```bash
py -m http.server 8000
```

(على ماك أو لينكس: `python3 -m http.server 8000`)

بعدها افتح المتصفح على: `http://localhost:8000`

لو تبي تجربها من جوالك على نفس الواي فاي: افتح `http://<IP جهازك>:8000`.

## طريقة اللعب

- **المستويات:**
  - سهل: 3 خيارات، والأسئلة الأشهر.
  - وسط: 4 خيارات، وكل الأسئلة.
  - صعب: 4 خيارات، وأحيانًا تلميح مكتوب بدل الصورة، وترتيب الأقسام عشوائي.
- **القلوب:** معك قلبين ❤️❤️. كل إجابة غلط تنقّص قلب، ولو خلصوا تنتهي اللعبة.
- **ما فيه وقت:** خذ راحتك في التفكير، ما فيه مؤقت.
- **النقاط:** الإجابة الصح = 10 نقاط، وكل 3 صح ورا بعض 🔥 = بونص 15.
- **50/50:** مرة وحدة في اللعبة.
- **جولة سريعة:** 10 أسئلة عشوائية من كل الأقسام.
- **الكيبورد والريموت:**
  - `1`–`4` للخيارات، والأسهم للتنقل، و`Enter` للتالي.
  - `M` كتم، و`Esc` لإنهاء اللعبة.
- الاسم والمستوى والأقسام والصوت وأفضل النتائج كلها تنحفظ في المتصفح.

## إضافة أو تعديل الأسئلة

كل المحتوى في ملف واحد: **`data/questions.json`**. ما تحتاج تلمس الكود.

### سؤال بصورة (فنان، رابر، غرض، ترند)

```json
{
  "id": "wardi",
  "section": "artists",
  "group": "عمالقة الطرب",
  "type": "image",
  "difficulty": "easy",
  "prompt": "مين هذا الفنان؟",
  "image": "public/images/wardi.webp",
  "answer": "محمد وردي",
  "distractors": ["محمد الأمين", "عثمان حسين", "عبد الكريم الكابلي"],
  "nickname": "فنان أفريقيا الأول",
  "nicknameEn": "The First Artist of Africa",
  "hint": "تلميح يظهر بدل الصورة في المستوى الصعب (أو null)",
  "bio": "التعريف اللي يطلع في البطاقة بعد الإجابة."
}
```

### سؤال كلمة من اللهجة

```json
{ "id": "w-zol", "section": "home", "group": "كلمات اللهجة", "type": "word", "difficulty": "easy",
  "word": "زول", "answer": "شخص، أو أي إنسان بشكل عام", "distractors": ["بيت صغير", "حيوان أليف", "طريق ترابي"] }
```

### سؤال نصي بدون صورة (مثل الأدب)

```json
{ "id": "lit-x", "section": "literature", "group": "روايات", "type": "text", "difficulty": "medium",
  "prompt": "نص السؤال؟", "answer": "الجواب", "distractors": ["غلط 1", "غلط 2", "غلط 3"], "bio": "تعريف قصير." }
```

### معنى الحقول

| الحقل | معناه |
|---|---|
| `id` | اسم فريد بالإنجليزي، بدون مسافات |
| `section` | القسم: `artists` أو `rappers` أو `home` أو `literature` (أو قسم جديد) |
| `group` | عنوان فرعي يظهر فوق السؤال |
| `type` | `image` أو `word` أو `text` |
| `difficulty` | `easy` أو `medium` أو `hard` |
| `distractors` | 3 خيارات غلط (في المستوى السهل نستخدم اثنين منها عشوائيًا) |
| `review` | (اختياري) ملاحظة لك إن السؤال يحتاج مراجعة، وما تظهر للاعب |

الخيارات تترتب عشوائيًا كل مرة.

### إضافة صورة

حط الصورة في `public/images/` ويفضّل تكون **WebP** وعرضها 640px أو أقل. لو صورتك JPG أو PNG تقدر تحوّلها بـ:

```bash
py -c "from PIL import Image; im=Image.open('in.jpg'); im.thumbnail((640,640)); im.save('public/images/name.webp', quality=80)"
```

### إضافة قسم جديد

1. أضف القسم في `sections` داخل `questions.json`:
   ```json
   { "id": "food", "title": "الأكل السوداني", "subtitle": "من الكسرة للعصيدة", "icon": "jebena" }
   ```
   الأيقونات المتاحة: `oud`، `mic`، `headphones`، `phone`، `jebena`، `zeer`، `angareeb`، `mabkhar`، `chat`، `book`، `bolt`.
2. أضف أسئلته وحط في كل سؤال `"section": "food"`.

القسم يطلع تلقائيًا في شاشة البداية والإعداد.

### بعد أي تعديل

غيّر رقم الإصدار في أول سطر من `sw.js` (مثلًا `v5` إلى `v6`)، ولو عدّلت الكود أو التصميم غيّر كمان `?v=5` في `index.html` لنفس الرقم، عشان الأجهزة اللي فتحت اللعبة قبل تحمّل الصور الجديدة للاستخدام بدون نت.

## النشر على الإنترنت

اللعبة ملفات ثابتة، فتقدر ترفعها على أي استضافة مجانية.

### Netlify (الأسهل)

1. ادخل [app.netlify.com/drop](https://app.netlify.com/drop).
2. اسحب مجلد `sudan-challenge` كامل وأفلته في الصفحة.
3. خلاص! يعطيك رابط تقدر تشاركه.

### Vercel

1. ارفع المجلد على GitHub.
2. من [vercel.com/new](https://vercel.com/new) اختر المستودع.
3. Framework: **Other**، واترك أوامر البناء فاضية، و Output Directory: `.`

### GitHub Pages

ارفع المجلد على مستودع، وبعدها من **Settings ← Pages** اختر الفرع `main`.

> بعد النشر، افتح الرابط من الجوال واختر «إضافة إلى الشاشة الرئيسية»، وتصير مثل التطبيق وتشتغل بدون نت.
